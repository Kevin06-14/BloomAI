\# BloomAI：花卉图像分类与数据分析



\## 1. 项目简介



本项目计划使用 Python 和 PyTorch 实现花卉图像分类，并对花卉数据集进行统计分析和可视化。

\- 学习 Python 项目开发与环境管理。

\- 使用 NumPy、Pandas 和 Matplotlib 进行数据处理与可视化。

\- 完成模型训练、验证和新图片预测。

\- 使用 Git 记录真实的开发过程。
